⚙️ How It Works

  1. Allow camera permission.
  2. Start the camera.
  3. Point the camera at an object.
  4. Click Capture Photo.
  5. The captured image is sent to the AI.
  6. YOLO detects the object.
  7. Bounding boxes are displayed.
  8. Object name and confidence are displayed.
  9. Voice announces the detected object.

Model: YOLO custom-trained object detection model
